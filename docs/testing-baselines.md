_Originally recorded 14 September 2026; reconciled through the bounded Phase E7 projectile block on 18 September 2026._

The game visual references are `tests/browser/canvas.spec.js-snapshots/current-map-chromium-desktop-win32.png`, `dense-late-game-chromium-desktop-win32.png`, and the `maps-*-chromium-desktop-win32.png` strategic/close matrix beside them. The earlier Phase E1 update to the same dense reference removed an extra-frame race when `freezePresentation()` began cancelling its pending RAF. `pixi-hybrid` uses semantic/pixel order checks, explicit conflict-to-full-Canvas pixel parity, focus dash segment/pixel parity, exact painted-edge contracts, and direct primitive, structure, type, color, position, identity, ownership, motion-policy, and fallback diagnostics rather than a final-art golden.

Production Pixi exclusion is a runtime and JavaScript-module-graph contract: production has no selectable/reachable Pixi renderer and emits no Pixi JavaScript chunk. Inert `.pixi-*` rules may remain in the shared stylesheet, so tests and documentation must not broaden that claim to zero Pixi text in every built asset.

Node.js 22.12 or newer within the 22.x line is the supported test and CI runtime; `package.json`, the lockfile, and locked Vite now agree on that range. Node 24 on Windows is excluded because it has been observed to be unstable during local simulation runs; changes should not broaden the declared engine range until that environment is reliable.

The required Phase A desktop display-scale suite uses Chromium emulation at DPR 1, 1.5, and 2 over 1280 x 720 and 1600 x 900 viewports. It checks the legacy CSS-pixel Canvas backing contract, rendered content, containment, coordinate targeting, resize camera stability, and browser/request errors. Emulated DPR does not qualify physical displays, operating-system scaling, text readability, compositor output, or input latency. Mobile projects remain advisory and are not part of `npm run verify`.

The optional Phase A browser performance harness and its measurement limitations are documented in `docs/browser-performance-baseline.md`. Its generated JSON is ignored and is not part of `npm run verify` because local browser timings are machine-relative. The current harness qualifies the Canvas production path and has no renderer-selection option, so it does not produce a Pixi performance result.

Normal non-Docker change verification is `npm run verify`; build reproducibility is `npm run test:build-reproducibility`. Release qualification additionally requires the mounted sandbox, security regression, and exact-artifact commands in `docs/build-a-release.md`, plus applicable performance/device and production checks. The pinned scope does not claim every seed, long-match outcome, browser rendering pixel identity, mobile visual identity, or production deployment approval. Smoke and restart tests deliberately use a 240x138 grid; the default determinism test retains the 720x414 production grid. Optional determinism environment overrides still test run-to-run equality but intentionally do not compare against the default baseline.

The corrected E7 fallback gate distinguishes recoverable projectile-layer rejection from fatal update or final-submission failure. Synthetic layer rejection must execute the complete Canvas painter and provide per-semantic pixels, primitive order, and final state; a boolean inferred from failed ownership is not evidence. Test-guarded Pixi evidence performs real `app.render()` and transparent per-Graphics extraction at DPR 1, 1.5, and 2, requiring pixels and CSS-position bounds for every primitive plus an ordered overlap pixel; visibility and tracked resources are restored. Fatal final-render and update-throw probes compare the actual synchronous full-frame Canvas retry with an identical-timestamp no-projectile Canvas baseline. Exact expected masks are generated per model primitive and independently omittable fill/stroke operation, never as merged semantic unions. Every stable semantic/index/operation key must retain nonzero pixels after all other masks are subtracted and must contain an actual framebuffer differential; all pairwise exclusive-mask intersections are zero, and removing each mask recomputes a reduced evidence total. The mask painter only locates expected geometry and cannot itself satisfy evidence. Retained missile and aircraft crops are nontrivial and unchanged by baseline removal. The observable same-frame fingerprint covers draw-mutated effects, labels, banner and inactive credits state, audio call/throttle state, input/selection, interpolation descriptor/token/count, ship/shell maps, visual shots, canonical bytes/hash, RNG, tick, and RAF pending/callback/render counters. It proves seeded effects and visual shots advance once and no RAF callback intervenes; it does not qualify active credit-roll retry behavior or unobservable browser/GPU internals. Historical pass counts and release hashes above describe their recorded runs, not this uncommitted evidence update.
